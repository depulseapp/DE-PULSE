# DE.PULSE v18.0.1 TEST — Principal Engineer Review

## Review posture

v18.0.1 is a separate TEST slice built from the qualified v18.0.0 identity/session foundation, itself anchored to the authoritative v17.5.1 Stable baseline. v17.5.1 remains the authoritative Stable release. This review covers Smart Intelligent Provider Router v2 + Rapid Move / Market Shock Foundation and inherited v18.0 security/session safety. It does not authorize Stable promotion.

## Canonical ownership / architecture

- The existing Provider Router remains the single executable provider-routing authority; v18.0.1 enriches it rather than adding a parallel router.
- Capability/entitlement state, deterministic provider scoring, Preferred vs Serving truth, per-capability circuits, latency evidence, and calls-avoided telemetry are owned by the canonical routing path.
- Rapid Move consumes canonical quote/provider-observation/event state and reuses Opportunity Radar, Smart Notification and live-priority mechanisms; it is not a second scanner.
- Deterministic Day/Swing/Long formulas remain unchanged.
- The No Execution Boundary remains unchanged.

## Provider intelligence / capacity truth

- NOT_ENTITLED is classified distinctly from provider outage and is suppressed with bounded revalidation rather than repeatedly probed.
- Circuit health is capability-scoped so failure of one provider capability does not incorrectly disable unrelated capabilities.
- Preferred provider and Serving provider are distinct concepts, with deterministic reason text when serving differs from preferred.
- Provider selection remains deterministic in production; adaptive usefulness learning is evidence-generating and SHADOW-first.
- Coverage Truth is explicit: short-window Rapid Move coverage is TIERED_PARTIAL for symbols receiving current canonical observations. The app does not claim full U.S.-market 15s/30s/60s surveillance without an entitled broad event feed.

## Rapid Move / Market Shock intelligence

- The production detector evaluates 15s/30s/60s/2m/5m windows using event/provider timestamps and bounded in-memory history.
- A roughly 5% one-minute move is a strong baseline trigger, not the entire intelligence policy.
- Materiality also considers price/liquidity, volume acceleration where available, source agreement, corporate-action/mechanical state, market context, catalyst evidence and current actionability.
- Mechanical/split-like moves, low-price noise and source-conflict cases are suppressible rather than blindly alerting.
- A genuine unexplained rapid move may surface before a news headline arrives; catalyst state can later escalate the same event.
- Alert delivery is event-first through SSE, with a bounded header banner plus Smart Notification persistence and Opportunity Radar/live-priority promotion.
- Event identity, point-in-time decision evidence and outcome state support later replay and adaptive learning.

## Adaptive intelligence governance

- Production alert/routing behavior remains deterministic and explainable.
- Adaptive learning follows SHADOW → VALIDATED → APPROVED → PRODUCTION; no learned policy silently self-modifies production.
- Point-in-Time Truth, evidence lineage, provider usefulness, false-positive/miss analysis and outcome learning are part of the committed adaptive path.
