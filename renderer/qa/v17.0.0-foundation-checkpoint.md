## Open release-engineering blocker

`persistence_backend_sqlite.go` is native SQLite for CGo-capable non-Windows targets. The current Windows / `CGO_ENABLED=0` route remains a JSON compatibility fallback, so **cross-platform desktop v17 packaging is BLOCKED** by `v17_0_cross_platform_persistence_gate.py`.

This does not invalidate host/source TEST work, but it prevents claiming a complete v17 desktop package or Stable promotion. The fallback must be replaced with a validated CGo-free SQLite implementation or every supported desktop target must be built with a native SQLite-capable toolchain before packaging.
