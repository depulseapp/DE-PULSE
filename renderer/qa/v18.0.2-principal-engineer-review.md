# DE.PULSE v18.0.2 TEST — Principal Engineer Review

## Finding
G14 exposed a release-integrity defect: source fingerprint identity depended on host path semantics. Windows and POSIX hosts could disagree for identical source bytes.

## Architecture correction
A single `source_fingerprint.py` owner now canonicalizes relative path keys and is reused by CI, pre-freeze, and certification. This removes three duplicated fingerprint implementations and strengthens REUSE → CONSOLIDATE → REFACTOR.

## Scope safety
The patch is delivery/build-process only. Smart Router v2, Rapid Move, provider routing behavior, deterministic Day/Swing/Long formulas, and the No Execution boundary remain inherited and protected. v17.5.1 Stable remains untouched.

## Decision
**PASS — GO to v18.0.2 pre-freeze/full regression and native G14/G15 recertification.**
