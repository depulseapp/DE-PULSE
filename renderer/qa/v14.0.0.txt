ISSUES FOUND AND FIXED DURING V14
1. Date-only official macro events could be interpreted as midnight events. Fixed: unknown times remain date-only and cannot falsely trigger Event Mode.
2. Options expected move initially used an overly broad chain IV average. Fixed: nearest-expiry, near-the-money IV is used; otherwise expected move is unavailable.
3. High-Impact Event Mode prewarm could repeat every five seconds during T-15. Fixed: prewarm work is de-duplicated per event.
4. Trade Readiness severity could allow a lower-priority conflict to downgrade CAUTION. Fixed with monotonic severity ranking.
5. FRED observation value was mapped with the wrong JSON tag. Fixed and covered by deterministic HTTP-provider test.
6. Options scope could over-poll chains. Fixed: refresh is constrained to the selected ticker plus a bounded set of relevant desk symbols.
7. Options IV-change context was missing from the approved scope. Added Delta IV from consecutive real snapshots only; no prior value is fabricated.
