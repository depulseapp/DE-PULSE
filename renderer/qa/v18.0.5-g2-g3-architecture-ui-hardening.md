# DE.PULSE v18.0.5 — G2/G3 Architecture & UI Readiness

## Decision
PASS — proceed with the focused v18.0.5 implementation.

## Reuse / consolidation
- Reuse the existing durable Day/Swing/Long watchlists, symbol registry persistence, bootstrap/state broadcast, quote-state/freshness logic, Opportunity Radar candidate model and Research workspace.
- Consolidate all user-managed cross-desk symbol operations behind `trackedSymbolsLocked`, `setTrackedSymbolLocked` and `clearTrackedSymbolsLocked`; do not add a competing symbol store or provider fetch path.
- Preserve explicit empty slices as durable truth so normalization cannot rehydrate defaults after Remove All.
- Discovery staging remains a distinct workflow and is not cleared by Tracked Symbols Remove All.

## UI dependency readiness
- Keep existing `data-master-*` API/event hooks internally for compatibility; change only user-facing terminology to Tracked Symbols.
- Opportunity Radar reuses existing candidate/promotions data and adds layout/status presentation only; deterministic qualification and promotion logic are unchanged.
- Research Target compaction is CSS-scoped to `.research-command-v2`; all Research views including Technical Context remain intact.
- Role visibility uses the authenticated principal already delivered by `/api/bootstrap`; USER/DEMO suppress implementation machinery while SUPER_OWNER/OWNER/ADMIN retain deep diagnostics.

## Data Utility / intelligence integrity
No new market dataset, provider feed, derived signal, model or background task is introduced. The patch consumes existing canonical evidence and reduces exposed implementation machinery.

## Risk controls
- v18.0.4 Stable remains immutable.
- v18.0.5 TEST uses `PersonalMarketTerminal-v18.0.5-TEST`.
- Protected deterministic Day/Swing/Long formulas are unchanged.
- No Execution Boundary is unchanged.
- v18.1 multi-user architecture remains out of scope.
