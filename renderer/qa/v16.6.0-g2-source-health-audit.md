## v16.6 architecture decision

The confirmed Master Symbol Store defect is handled by **REFACTOR**, not a new store:

- `setMembershipLocked` and symbol normalization preserve an explicitly empty list instead of collapsing it into the legacy `nil` sentinel.
- `nil` continues to mean missing/legacy state for migration; non-nil `[]` means the user intentionally has zero symbols.
- `/api/master-symbol/remove-all` mutates the existing DAY/SWING/LONG canonical watchlists only.
- Maintenance separates **User Master Symbol Store** from protected **System Market Context** and the VIX Special Index Store.
- Provider Router / `requiredSymbolsFromState` still retain protected context such as SPY/QQQ/GLD/SLV/USO without repopulating user desk membership.

Permanent order remains **REUSE → CONSOLIDATE → REFACTOR → DELETE/REPLACE → ADD**. No second symbol store, deterministic engine, provider scheduler or v16.7 feature path was introduced.
