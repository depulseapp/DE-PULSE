# DE.PULSE v16.8.0 — Performance Baseline

Pre-certification benchmark on the build host, 500 synthetic canonical symbols, `-benchtime=100x`:

- Heat Map 500 symbols: **~8.8 ms/op · ~4.95 MB/op · 9,172 allocs/op**.
- Liquidity 500 symbols: **~25.1 ms/op · ~14.0 MB/op · 22,523 allocs/op**.

Blocking release ceilings are deliberately wider to avoid host-noise false failures: Heat <150 ms/op and <12 MB/op; Liquidity <250 ms/op and <30 MB/op. Inherited G7/G12 also cover cache rewrite avoidance, concurrency/race, goroutine growth, full-suite load and provider/cross-module behavior.

This release adds no new broad fetch loop: heat reuses canonical quotes, seasonality reuses existing SPY/QQQ 10-year history, GEX reuses the options owner, liquidity reuses canonical quotes/bars, and notifications consume canonical state transitions.
