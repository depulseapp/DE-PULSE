# DE.PULSE v14.3.2 — Cross-Module Integration, Correlation & Placement Audit

## Header Notification / Alert Slot
- **Global header:** Integrated. Uses existing center lane; header height remains unchanged.
- **Settings:** Integrated through Save feedback; scroll/focus preserved.
- **Maintenance/Data Engine actions:** Integrated through success/warn/error feedback in the same header slot.
- **Dashboard/Day/Swing/Long/Discovery/Research/AI:** Intentionally no persistent notification panel; global header feedback is sufficient and prevents duplicate UI.
- **Placement decision:** Important transient operational feedback stays visible at any page scroll position without overlaying content or shifting layout. Long content truncates with a full `title` tooltip/accessibility text.

## Detailed Data Engine Manual Actions
- **Data Engine sidebar:** Integrated. Small contextual actions are adjacent to prep jobs and grouped under Manual Actions.
- **Pre-Market Prep:** Run Now → same `/api/cache/pre-market-prep` production path.
- **Market Open Prep:** Run Now → same `/api/cache/market-open-prep` production path.
- **Earnings & Material Catalyst Watch:** Evaluate → evaluates current sourced material trigger state only; it never fabricates an earnings/catalyst event.
- **Refresh Due Data:** Uses the existing low-priority stale-data refresh path and cache protections.
- **Global / FX:** Refreshes configured direct Twelve Data context plus official-close fallbacks without clearing good cache.
- **Provider Capabilities:** Rechecks current provider evidence/entitlements; configured keys alone never become AVAILABLE.
- **VIX:** Refresh is exposed only when stale/cached/degraded/unavailable and uses the validated direct → official → cache path.
- **Primary live stream:** Reconnect appears only in Live mode when the primary feed is degraded/fallback/idle; it closes the existing Finnhub socket so the same production reconnect loop re-authenticates/resubscribes while Alpaca fallback remains active. No duplicate stream loop is created.
- **Maintenance:** Existing deeper controls remain; Data Engine controls are convenience actions, not a duplicate Maintenance console.
- **Trading tabs:** Intentionally hidden as controls; only resulting canonical context/readiness is consumed.

## Gate 3 — Cross-Module Integration, Correlation & Reuse
PASS criteria: manual actions update canonical runtime state that is already consumed by relevant Market Regime, Dashboard, Day, Swing, Long, Decision Queue, Trade Readiness, Research, AI, Settings/Maintenance and documentation surfaces. No duplicate calculation path is introduced.
