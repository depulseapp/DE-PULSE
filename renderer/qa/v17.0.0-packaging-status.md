# DE.PULSE v17.0.0 — Packaging Status

The source/host implementation uses the SQLite backend when CGO is available. The current build host cannot download a CGo-free SQLite Go module and does not have a macOS/Windows CGo cross-toolchain.

Therefore **cross-platform desktop packaging is intentionally BLOCKED** while the `!cgo || windows` code path remains the JSON fallback. This is a release-engineering block, not permission to weaken the v17 SQLite contract.

The correct resolution is to replace the fallback with a validated CGo-free SQLite implementation (or build each platform with a native SQLite-capable toolchain), then rerun the cross-platform persistence gate before producing macOS/Windows v17 packages.
