The active release uses:

**diff → impact map → evidence inheritance → smallest affected execution → checkpoint → AIPLC → G10 full coverage reconciliation → immutable RC → full certification → independent native lanes → G16 learning.**

No process change may add a top-level gate beyond G0–G16. Use checkpoints, sub-stages, shards or strengthened ownership inside existing gates.
